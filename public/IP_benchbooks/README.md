# IP Benchbooks Directory

This directory contains IP benchbook PDF files that are displayed in the application.

## Required Files

Please add the following PDF files to this directory:

1. **philippines_benchbook.pdf** - The specific IP benchbook for the Philippines
2. **introduction_benchbook.pdf** - The default introduction benchbook shown for all other countries

## How It Works

- When users visit the Philippines benchbook page, they will see `philippines_benchbook.pdf`
- For all other countries, they will see `introduction_benchbook.pdf`

## Adding PDF Files

Simply place your PDF files in this directory with the exact names specified above. The application will automatically load and display them in the benchbook viewer.
